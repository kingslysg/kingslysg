## 💻 Code Portfolio

Four portfolio samples illustrating full-stack application flow, API-led integration, AI retrieval, and streaming data engineering.

### 🔗 MuleSoft Customer Profile API Platform

[![View Repository](https://img.shields.io/badge/GitHub-View_Repository-181717?logo=github&logoColor=white)](https://github.com/kingslysg/mule-react-customer-api-platform)

**Technology stack:** React · MuleSoft Anypoint Platform · Mule 4 · RAML · APIkit · DataWeave · CloudHub 2.0

A customer profile experience demonstrating API-led connectivity across Experience, Process, and mock System APIs.

**Project flow & highlights:**
- React sends a profile request to the Experience API, which delegates orchestration to the Process API and mock System API.
- RAML and APIkit define contract-first API specifications.
- Mule flows coordinate the request; DataWeave transforms the response.
- The sample documents service boundaries, request flow, and CloudHub 2.0 deployment considerations.

### 📈 Market Data Ingestion & ETL Platform

[![View Repository](https://img.shields.io/badge/GitHub-View_Repository-181717?logo=github&logoColor=white)](https://github.com/kingslysg/market-data-ingestion-etl-platform)

**Technology stack:** Java 21 · Spring Boot · Python · Apache Kafka · Spark Structured Streaming · Apache Airflow · PostgreSQL · Snowflake · Databricks · Next.js · React · TypeScript · AG Charts · Framer Motion

A market-data engineering sample presenting an event-driven ingestion and streaming ETL design with an operations dashboard. All market events are simulated.

**Project flow & highlights:**
- A mock generator produces quote and trade events; a Java/Spring Boot service publishes them to Kafka topics.
- Spark Structured Streaming represents validation, normalization, deduplication, idempotency verification, and NLP enrichment.
- Invalid or failed records are routed to a dead-letter queue (DLQ).
- PostgreSQL represents operational records and pipeline status. Snowflake and Databricks are optional analytical destinations.
- Apache Airflow DAGs illustrate scheduled ingestion, backfills, reconciliation, DLQ replay, and pipeline monitoring.
- A light dashboard concept uses Next.js, React, TypeScript, AG Charts, and Framer Motion to present pipeline health and simulated market activity.

*Airflow, Snowflake, Databricks, and other external services require separate configuration. See the repository README for the implementation currently available.*
