### 🤖 Sentinel AI Intelligence Platform

[![View Repository](https://img.shields.io/badge/GitHub-View_Repository-181717?logo=github&logoColor=white)](https://github.com/kingslysg/sentinel-ai-workbench)

**React · TypeScript · GraphQL · Python · FastAPI · RAG · AWS Bedrock Adapter**

An inspectable AI application demo showing how a question moves through retrieval, response generation, caching, and source attribution.

- Dataset-scoped retrieval and cited, grounded answers.
- NLP query processing and visible semantic-cache behavior.
- Provider adapters and inspectable safety stages.

<details>
<summary><strong>AI capabilities & demo boundaries</strong></summary>

- **Retrieval:** Document chunks, ranked results, grounded responses, and source citations.
- **NLP:** Query normalization, tokenization, stop-word filtering, term aliases, and intent hints.
- **Vector integration:** Milvus adapter boundary with an embedding callback. The default local demo uses lexical retrieval and does not generate real embeddings.
- **LLM integration:** Mock Bedrock-style provider by default; an AWS Bedrock Converse adapter is included for credentialed server-side setup.
- **Semantic caching:** Dataset-scoped in-memory similarity cache with TTL and visible cache hits.
- **Safety:** Inspectable policy stages. Portkey, Lakera Guard, and NeMo Guardrails integrations are simulated rather than live service calls.

**Additional stack:** Vite, Apollo Client, Node.js, Express, Pydantic, and AWS Bedrock SDK.

*Uses fictional data. No cloud credentials are required for the local demo. See the repository README for live-service prerequisites.*

</details>
