3. **[Sentinel AI Intelligence Platform](https://github.com/kingslysg/sentinel-ai-workbench)** — Full-stack AI portfolio demo where visitors ask questions across fictional knowledge bases and inspect the path from query to cited, grounded answer.
   - **RAG and retrieval:** Dataset-scoped document chunks, ranked retrieval, grounded responses, and source citations.
   - **NLP:** Query normalization, tokenization, stop-word filtering, term aliases, and intent hints.
   - **Embeddings and vector search:** Milvus adapter boundary with an embedding callback; zero-setup demo mode uses local lexical retrieval and does not create real embeddings.
   - **LLM integration:** Mock Bedrock-style provider is active by default; an AWS Bedrock Converse adapter is included for credentialed server-side setup.
   - **Semantic cache:** Dataset-scoped in-memory similarity cache with TTL and visible cache-hit behavior.
   - **Responsible AI:** Safety and policy stages are inspectable. Portkey routing, Lakera Guard, and NeMo Guardrails are demo integrations, not live service calls.
   - **Stack:** React, TypeScript, Vite, Apollo Client, GraphQL, Node.js, Express, Python, FastAPI, Pydantic, AWS Bedrock SDK, and a Milvus adapter.
*Sentinel uses fictional data. The local demo requires no cloud credentials; see its README for simulated provider adapters and prerequisites for live services.*
